# Computer Graphics in Java

**Exploring the fundamentals of 2D and 3D rendering — from individual pixels to complete graphics pipelines.**

This repository documents my hands-on learning in **Computer Graphics** as part of my B.Sc. in Software Engineering at Braude College of Engineering.

It serves as both a **personal backup** of my work and a **record of my progress** in graphics programming, computational geometry, and the mathematics behind rendering.

## What I'm Learning

### Ray Tracing
- Generating camera rays and mapping pixels to a 3D scene
- Ray–sphere intersections
- Lighting and material appearance
- Shadows, reflections, and refraction
- Basic texture mapping

### Rasterization
- Line drawing and triangle rasterization
- Barycentric coordinates and interpolation
- 2D/3D transformations using vectors and matrices
- Orthographic and perspective projection
- Viewport and camera transformations
- Depth testing and hidden-surface removal (Z-buffer)
- Lighting, shading, and texture mapping

### Graphics APIs
- Understanding the stages of the graphics pipeline
- Exploring how OpenGL implements rasterization

## Technologies & Concepts

- **Java** — practical graphics programming and algorithm implementation
- **JOML** — vector and matrix mathematics
- **OpenGL** — graphics API concepts and course exercises
- **Linear Algebra & Geometry** — transformations, projections, and intersections
- **Debugging & Visualization** — validating algorithms through rendered output

## Learning Projects

| Project | Focus |
| --- | --- |
| **Ray Tracing** | Building up a renderer through camera rays, intersections, lighting, shadows, and material effects |
| **Rasterization** | Exploring a software graphics pipeline through lines, triangles, transformations, depth, and shading |

The projects are developed incrementally during the course. **Topics listed here describe the learning scope, not a claim that every feature has already been implemented.**

## Why This Repository Exists

My goal is to understand **how rendering works under the hood**, rather than only using high-level graphics libraries. Working through these algorithms helps me strengthen my Java skills, mathematical reasoning, problem-solving, and understanding of the graphics pipeline.

This is an **ongoing educational repository**, not a production-ready graphics engine. I update it as I complete exercises and experiments.
